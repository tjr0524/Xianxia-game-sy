# 수선 비경 · 검로 개척록

직접 비경을 누비고 살아 돌아와 영구적으로 성장하는 모바일 우선 액티브 증분형 선협 게임입니다.

## 플레이

- 배포 주소: https://tjr0524.github.io/Xianxia-game-sy/
- 이동: 전장 탭/드래그 또는 WASD·방향키
- 공격: 기본 검격과 해금한 모든 법술이 독립 쿨타임으로 자동 발동
- 원정: 제한 시간 25초, 남쪽 중앙 귀환진으로 직접 복귀
- 실패: 해당 원정 전리품의 40% 회수

## 핵심 루프

1. 개방한 비경 중 원정할 지역을 선택합니다.
2. 시작 시 보이는 배치에서 목표와 귀환 동선을 정합니다.
3. 영초·영석을 확보하고 붕괴 전에 귀환합니다.
4. 수련 도맥, 법술, 비경 인연에 영구 투자합니다.
5. 경지를 돌파하고 새 비경과 기믹을 개방합니다.

기다림이 주가 되는 방치형이 아닙니다. 짧은 원정의 판단과 조작, 즉시 체감되는 성장, 새로운 시스템 해금을 중심으로 설계했습니다.

## v11 주요 변경

- 수련·법술·비경 개척을 잇는 확장형 도판
- 해금한 모든 법술의 독립 재사용 대기시간과 자동 발동
- 처치 연계 보너스 `검세`와 비경별 최고 기록
- 산수가 가진 실물 비보와 수행 목표 보상
- 축기 이후 신규 비경 `천뢰봉` 및 낙뢰 회피 기믹
- 비경별 절차적 배경, 개체 실루엣, 전투·채집 효과
- 범인 첫 원정 완화 및 수선 입문 시 어검술 자동 전승
- v4~v10 저장 데이터 자동 이전

## v11.24 백색 수묵 UI 및 직접 해금 수정

- 아이보리 한지 여백과 옅은 먹청 산수를 중심으로 한 백색 테마
- 먹색 본문, 옥빛 상호작용, 제한적인 금색 강조로 정보 위계 재정리
- 전투 HUD, 수련 도맥, 법술 검맥도, 비경 지도, 도행록을 밝은 카드 체계로 통일
- 다음 경지 노드를 눌러 해당 경지의 해금 버튼을 바로 여는 직접 해금 동작 수정
- v11.22 모바일 하단 패널 동작과 기존 저장 데이터 호환 유지

게임 규칙, 보상, 비용, 해금 조건, 저장 형식은 그대로이며 경지 선택 UX와 화면 표현만 수정했습니다.

## 지역 구성

| 비경 | 주요 요소 | 권장 경지 |
|---|---|---|
| 청운산 후산 | 영초, 일반 요수 | 범인~연기 3층 |
| 흑풍곡 | 산수, 탐보서, 비보 | 연기 3~6층 |
| 적혈비경 | 영맥, 정예 수호수 | 연기 6~9층 |
| 천뢰봉 | 낙뢰 예고·회피, 뇌정 보상 | 축기 1층 이상 |

각 비경의 인연 트리와 기록은 따로 저장됩니다. 상위 비경에 갔다가 돌아와도 이전 지역 진행도는 유지됩니다.

## 개발 및 검증

별도 빌드 과정 없이 `index.html`을 실행합니다. 정적 호스팅은 GitHub Pages를 사용합니다.

```bash
node --check game_v11.js
node --check visual_v11_23.js
node --check visual_v11_24.js
node tests/v11_regression.cjs
node tests/v11_23_visual.cjs
node tests/v11_24_visual.cjs
node tests/v11_24_stage_unlock.cjs
```

회귀 검사는 저장 이전, 지역별 개체 구성, 영맥·정예, 천뢰 판정, 25초 종료, 실패 시 40% 회수, 첫 원정·입문 직후 생존성과 보상 획득을 확인합니다.

이전 안정 버전인 `game_v10.js`와 보조 파일은 비교·복구를 위해 보존합니다. 현재 진입점은 `game_v11.js`입니다.
