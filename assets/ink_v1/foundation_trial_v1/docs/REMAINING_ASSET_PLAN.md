# 축기 맵 잔여 에셋 제작 순서

캐릭터 에셋은 축기 수문장, 일반 요수 5종, 태허유적 수호령 2종, 태허진령까지 완료했다. 이후에는 맵·UI·전투 효과만 제작한다.

| 순서 | 지역 | 제작 항목 | 현재 상태 |
|---:|---|---|---|
| 1 | 태허유적 | 태허진령 초상, 태허유적 지도 노드 | 완료 |
| 2 | 태허유적 | 배경, 진법 결절, 유적 환경 장식 | 완료 |
| 3 | 자운택 | 배경, 습지 환경 장식, 자운 안개·수면 효과, 지도 노드 | 완료 |
| 4 | 천뢰봉 | 기존 낙뢰·전도 효과 대조, 피뢰 결절 | 완료 |
| 5 | 공통 효과 | 수호막 파괴 효과, 독립 장판 효과 | 완료 |

## 중복 제작 방지

- 천뢰봉의 환경 낙뢰 애니메이션과 낙뢰 바닥 흔적·전도 효과는 기존 프로젝트 에셋을 먼저 대조한다.
- 돌진, 원거리 투사체, 폭발, 호령 준비·발동, 호령 강화 문양, 수호막·수호 상태 문양은 각 요수 폴더의 전용 에셋을 재사용한다.
- 태허진령의 진법 공격과 이동 영역은 `boss/taixu_formation_sovereign/`의 기존 시트를 사용한다.
- 별도 신규 제작은 실제로 비어 있는 맵 환경과 공통 파괴·장판 표현에 한정한다.

## 완료 상태

계획했던 축기 시련·천뢰봉·자운택·태허유적의 신규 캐릭터, UI, 맵 환경, 상호작용 오브젝트와 전투 효과 제작을 완료했다. 이후 작업은 밸런스 수치 확정 뒤 런타임 연결과 실제 화면 크기 검수다.
