# 노드 아이콘 사용 규격

## 기본 규격

- 원본 아이콘: `256×256 PNG`, 투명 배경
- 소형 런타임본: `64×64 PNG`, 투명 배경
- 실제 도형 안전 영역: 최대 `216×216 px`
- 아이콘과 상태 프레임은 분리된 레이어다.
- 합성 순서: `노드 배경 → 아이콘 → 상태 프레임 → 단계/수치 배지`

## 트리 적용 원칙

- 검결·체수련·경신법·신식·호체는 단계마다 새 그림을 만들지 않고 같은 계통 아이콘을 쓴다.
- 단계 차이는 노드 연결선, 상태 프레임, 작은 숫자 또는 별도 단계 배지로 나타낸다.
- 고유 패시브와 전투 방식이 실제로 달라지는 노드만 별도 아이콘을 사용한다.
- 한자 한 글자를 아이콘처럼 사용하지 않는다. 노드명은 필요할 때 아이콘 아래 한글 텍스트로 표시한다.

## 상태 프레임

| 프레임 | 용도 |
|---|---|
| `frame_locked` | 조건 미달 또는 잠긴 노드 |
| `frame_available` | 현재 해금 가능한 노드 |
| `frame_selected` | 선택 중인 노드 |
| `frame_mastered` | 습득·완성된 노드 |

## 폴더

- `training_core`: 다섯 수련 계통과 초기 핵심 패시브
- `training_advanced`: 고급 수련 패시브
- `combat_abilities`: 기본 공격, 자동 술법, 신법 계열
- `combat_modifiers`: 위력·범위·연쇄 같은 범용 전투 변형
- `combat_mechanics`: 회피 분기 및 적 전투 기믹
- `expedition`: 생태·기연·영맥 탐험 트리
- `battlefield`: 맵 사건, 진법, 관문, 보상 노드
- `node_frames`: 상태 프레임
- `source_generated`: 분리 전 생성 원본

정확한 파일 경로와 한글 표기는 `node_icon_manifest.json`을 기준으로 한다.
