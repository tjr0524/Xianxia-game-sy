# 캐릭터 스프라이트 제작 프로토콜 v1

## 목적

프레임마다 캐릭터 크기가 달라지거나, 큰 이펙트 때문에 본체가 축소되는 문제를 방지한다. 런타임에서는 캐릭터별 공통 스케일 하나만 사용하며 프레임별 보정값을 두지 않는다.

## 1. 기준 원화 잠금

- 정면 또는 측면의 중립 자세 기준 원화 1장을 먼저 확정한다.
- 색, 얼굴, 뿔·무기·의상, 몸통 비율을 이후 모든 생성의 불변 조건으로 사용한다.
- 기준 원화 승인 전에는 애니메이션 시트를 만들지 않는다.

## 2. 본체 포즈와 이펙트 분리

- 1차 생성: 캐릭터 본체만 생성한다. 공격 궤적, 연기, 잔상, 먼지, 광원은 넣지 않는다.
- 2차 생성: 확정된 본체 포즈를 참조하여 이펙트 전용 레이어를 생성한다.
- 납품물은 `body`, `fx`, `combined` 3종을 유지한다.
- 이펙트 크기는 본체 스케일 산정에 절대 포함하지 않는다.

## 3. 공통 셀과 피벗

- 기본 셀: 256×256 RGBA.
- 공통 지면 피벗: `(128, 224)`.
- 지상 자세의 발 기준선 오차: ±2px.
- 모든 셀 외곽 1px은 완전 투명이어야 한다.
- 런타임 확대·축소는 캐릭터별 공통값 하나만 허용한다.

## 4. 크기 기준

- 사족보행 캐릭터는 전체 알파 바운딩 박스가 아니라 `어깨–엉덩이 몸통 길이`와 `머리 크기`를 기준으로 한다.
- 사람형 캐릭터는 `머리 높이`와 `골반–어깨 길이`를 기준으로 한다.
- 기준 원화 대비 몸통 길이 허용 편차: ±5%.
- 기준 원화 대비 머리 크기 허용 편차: ±7%.
- 웅크림·점프·사망 자세는 전체 높이가 달라도 되지만 해부학적 크기는 유지한다.

## 5. 제작 순서

1. 기준 원화 승인
2. 이펙트 없는 본체 포즈 스트립 생성
3. 동일 피벗과 해부학적 크기로 본체 정규화
4. 본체 시트 검수
5. 이펙트 레이어 생성 및 배치
6. `body`, `fx`, `combined` 시트 조립
7. 정적 그리드와 실제 속도 GIF 검수
8. 자동 검사 통과 후 납품

## 6. 자동 검사 항목

- 지정된 열×행과 셀 크기
- 프레임 수 및 파일명 연속성
- RGBA 및 투명 배경
- 외곽 알파 0
- 최소 안전 여백
- 인접 셀 침범 없음
- 지면 기준선 및 피벗
- 본체 크기 메타데이터 존재
- ZIP 무결성
- 보행 루프의 좌우 앞다리 접지 위상 교대
- 뒷다리는 앞다리와 반대 위상인지 확인
- 같은 쪽 발만 반복해서 딛는 인상 여부를 실제 속도 GIF로 확인

## 7. 반려 조건

- 프레임별로 본체를 셀 최대 크기에 맞춘 경우
- 이펙트까지 포함한 바운딩 박스로 본체 크기를 결정한 경우
- 프레임별 런타임 스케일 보정이 필요한 경우
- 정적 시트만 확인하고 애니메이션 미리보기를 확인하지 않은 경우
- 뿔, 꼬리, 무기, 이펙트가 셀 경계에 닿는 경우
