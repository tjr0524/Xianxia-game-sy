# Ink asset pack v1

게임에 적용된 수묵 담채 에셋 묶음입니다. 모든 플레이어·요수·오브젝트·법술 시트는 원본 해상도로 `source/`에 보존하고, 잘라 쓴 배경 및 UI 조각은 `runtime/`에 둡니다.

- 플레이어: 4등신 백의·묵청 검객, idle 4 / move 6 / attack 6
- 일반 요수: 비경마다 수호형 1종 + 추격형 1종, move 6 / attack 6 / death 4
- 월드: 자유 이동용 3/4 탑다운 비경 배경 4종, 3등급 영초, 귀환진, 비보·영맥 소품
- 법술: 어검 / 검풍 / 비검 / 낙뢰 / 만검진, 각 4프레임
- UI: 엠블럼, 20개 아이콘, 패널·버튼·노드, 비경 지도, 수련 도맥 배경

프레임 좌표와 파일 역할은 `manifest.json`을 기준으로 합니다. 런타임은 각 프레임의 불투명 영역을 계산한 뒤 발밑 중앙을 고정하여, 원본 시트 안의 여백이나 그림 위치가 달라도 대기·이동 애니메이션의 중심이 흔들리지 않습니다.
